# Service sitelinks — November 1, 2026

[Copy-ready sitelink text, descriptions and URLs](GOOGLE_ADS_SITELINKS.csv) cover all ten current services. Each URL opens a distinct service page on easytowing.ca. Use the four CSV fields when adding sitelinks in your existing Google Ads account. The file is a copy reference; campaign/account associations are not included for a bulk Editor import. No Google Ads account or live campaign has been changed.

The text is within Google's 25-character link-text limit and 35-character limit for each description line. Each row has unique link text and a service-specific destination on the same domain. Add assets only to campaigns or ad groups for which they are relevant. Sitelink eligibility, approval and whether Google displays an asset are decided by Google; a valid landing page does not guarantee approval or display.

Sources checked November 1, 2026: [Google Ads sitelinks](https://support.google.com/google-ads/answer/2375416?hl=en), [sitelink asset requirements](https://support.google.com/adspolicy/answer/1054210?hl=en), [Google Ads SitelinkAsset field limits](https://developers.google.com/google-ads/api/reference/rpc/v25/SitelinkAsset).
